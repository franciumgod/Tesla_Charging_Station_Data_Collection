# How to use?

To collect data from the Tesla Find Us website, first run collect_stations_location.py to generate a JSON file with basic station information. Then, run get_charger_details.py for charger details or get_location_details.py for location details.

By the way, the charger data has been collected and stored in the `charger` folder

# Requirements

- Python 3.9.25
- Run `pip install -r requirements.txt`
